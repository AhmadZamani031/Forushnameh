# فروش‌نامه

نرم‌افزار فارسی و راست‌چین مدیریت فروش، فاکتور، کالا، مشتری، موجودی و دریافت‌های مشتریان.

**نسخهٔ آنلاین:** https://ahmadzamani031.github.io/Forushnameh/

## امکانات فعلی

- ثبت‌نام، ورود و بازیابی رمز عبور با Supabase Auth
- مدیریت کالاها، قیمت‌ها، حداقل موجودی و موجودی انبار
- ثبت اتمیک کالای جدید همراه با موجودی اولیه
- مدیریت مشتریان
- صدور فاکتور با تاریخ شمسی و شماره‌گذاری ترتیبی
- ثبت گردش انبار و جلوگیری از موجودی منفی
- مشاهده فاکتورهای صادرشده
- ثبت دریافت نقدی، کارت‌خوان، انتقال بانکی و سایر روش‌ها
- نمایش وضعیت پرداخت‌نشده، پرداخت جزئی و تسویه‌شده
- برگشت دریافت با حفظ سابقه مالی و بدون حذف یا ویرایش رکورد اصلی
- خروجی فاکتور به‌صورت PNG و PDF
- داشبورد و گزارش فروش با خروجی PDF و CSV
- تنظیمات کسب‌وکار و واحد پول
- دریافت نسخه پشتیبان JSON از اطلاعات ابری، شامل دریافت‌ها و برگشت‌ها

## فناوری‌ها

- HTML، CSS و JavaScript
- Supabase Auth و PostgreSQL
- html2canvas و jsPDF
- GitHub Pages

## ذخیره‌سازی و امنیت

اطلاعات در PostgreSQL ذخیره می‌شوند. سیاست‌های Row Level Security دسترسی به داده‌ها را به حساب مالک محدود می‌کنند. صدور فاکتور، ثبت گردش انبار و اعتبارسنجی دریافت‌ها در پایگاه داده کنترل می‌شوند.

دریافت‌ها و برگشت‌ها به‌صورت دفتر ثبت append-only نگهداری می‌شوند؛ کاربران عادی اجازه ویرایش یا حذف سوابق پرداخت را ندارند. برای اصلاح دریافت اشتباه باید سند برگشت ثبت شود.

در کد سمت کاربر فقط کلید عمومی Publishable استفاده می‌شود. کلیدهای Secret و Service Role و رمز پایگاه داده نباید در مخزن یا مرورگر قرار بگیرند.

## پشتیبان‌گیری

از بخش پشتیبان‌گیری می‌توان فایل JSON شامل تنظیمات، کالاها، مشتریان، فاکتورها، اقلام فاکتور، دریافت‌ها و گردش‌های انبار دریافت کرد. بازیابی فایل در برنامه هنوز فعال نیست؛ فایل پشتیبان را در مکانی امن نگهداری کنید.

## اجرای محلی

۱. مخزن را دریافت کنید.
۲. فایل `index.html` را با مرورگر باز کنید.
۳. برای ورود، ذخیره‌سازی ابری و دریافت خروجی فاکتور به اینترنت نیاز دارید.

## گزارش مشکل

برای گزارش خطا یا پیشنهاد، از بخش Issues مخزن استفاده کنید. در گزارش‌ها رمز عبور، کلیدهای محرمانه و اطلاعات شخصی مشتریان را قرار ندهید.
