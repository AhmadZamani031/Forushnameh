# فروش‌نامه

نرم‌افزار فارسی و راست‌چین مدیریت فروش برای کسب‌وکارهای کوچک.

**نسخهٔ آنلاین:** https://ahmadzamani031.github.io/Forushnameh/

## نسخه فعلی: ۱۴

## قابلیت‌ها

- ثبت‌نام، ورود، خروج، تأیید ایمیل و بازیابی رمز عبور با Supabase Auth
- مدیریت کالاها و خدمات، قیمت، موجودی و حداقل موجودی
- ثبت اتمیک کالای جدید همراه با موجودی اولیه و دفتر گردش انبار
- مدیریت مشتریان
- صدور فاکتور با تاریخ شمسی، شماره‌گذاری ترتیبی، تخفیف و مالیات
- جست‌وجو و فیلتر فاکتورها بر اساس شماره، مشتری، تاریخ و وضعیت پرداخت
- مشاهده جزئیات، چاپ مجدد و خروجی PNG/PDF فاکتور
- دفتر دریافت وجه با روش‌های نقدی، کارت‌خوان، انتقال بانکی و سایر روش‌ها
- وضعیت پرداخت‌نشده، پرداخت جزئی و تسویه‌شده
- ابطال فاکتور با حفظ سوابق، برگشت موجودی و الزام برگشت دریافت‌ها
- برگشت دریافت با ثبت سند جبرانی و حفظ سوابق غیرقابل‌ویرایش
- گزارش فروش، نمودارها و خروجی PDF/CSV
- تنظیمات کسب‌وکار و واحد پول
- خروجی پشتیبان JSON و بازیابی کنترل‌شده نسخه ۶ فقط در فضای کاری خالی
- تم روشن (پیش‌فرض) و تاریک با انتخاب ماه/خورشید و ذخیره ترجیح
- PWA قابل نصب با کش پوسته و صفحه آفلاین؛ عملیات حساب و داده‌ها همچنان به اینترنت نیاز دارند

## فناوری‌ها

- HTML، CSS و JavaScript بدون فریم‌ورک
- Supabase Auth و PostgreSQL
- GitHub Pages
- Service Worker و Web App Manifest
- html2canvas و jsPDF

## داده‌ها و امنیت

داده‌ها در PostgreSQL نگهداری می‌شوند. سیاست‌های RLS و توابع دیتابیس مالکیت و اعتبارسنجی عملیات حساس را کنترل می‌کنند. دریافت‌ها و برگشت‌ها به‌صورت دفتر ثبت append-only نگهداری می‌شوند؛ اصلاح دریافت با سند برگشت انجام می‌شود.

در مرورگر فقط کلید عمومی Publishable استفاده می‌شود. هرگز Service Role Key، رمز دیتابیس یا کلیدهای محرمانه را در مخزن یا کد سمت کاربر قرار ندهید.

## پشتیبان‌گیری و بازیابی

از برنامه فایل JSON پشتیبان دریافت کنید و آن را در مکانی امن نگه دارید. بازیابی نسخه ۶ فقط در فضای کاری خالی مجاز است و داده موجود را پاک یا جایگزین نمی‌کند. پیش از استفاده عملی، فایل پشتیبان را در یک حساب آزمایشی خالی بازیابی و صحت شمارش و مانده‌ها را بررسی کنید. فایل‌های قدیمی‌تر باید ابتدا با نسخه جاری پشتیبان‌گیری مجدد شوند.

## اجرای محلی

مخزن را دریافت و از طریق یک وب‌سرور محلی اجرا کنید. برای Auth، ذخیره‌سازی ابری، گزارش‌ها و خروجی‌های وابسته به کتابخانه‌های بیرونی، اتصال اینترنت لازم است.

## گزارش مشکل

از بخش Issues مخزن برای گزارش خطا استفاده کنید. رمز عبور، کلیدهای محرمانه و اطلاعات شخصی مشتریان را در Issue یا گزارش عمومی قرار ندهید.

## نسخهٔ ۱۴ — مدیریت حساب
- حذف دائمی حساب کاربری از بخش تنظیمات اضافه شد.
- حذف حساب نیازمند ورود مجدد با رمز عبور، تطبیق ایمیل و واردکردن عبارت تأیید است.
- پاک‌سازی سمت سرور تمام داده‌های نسخه فعلی و جداول قدیمی را پوشش می‌دهد؛ کلید مدیریتی در مرورگر قرار نمی‌گیرد.
- پیش از حذف، هشدار روشن درباره غیرقابل‌بازگشت بودن عملیات و توصیه به تهیه پشتیبان نمایش داده می‌شود.
- Edge Function اختصاصی `delete-account` احراز هویت و رمز عبور را دوباره بررسی می‌کند، سپس داده‌ها و حساب Auth را حذف می‌کند.
