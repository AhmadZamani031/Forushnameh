# فروش‌نامه

نرم‌افزار فارسی و راست‌چین مدیریت فروش برای کسب‌وکارهای کوچک.

**نسخهٔ آنلاین:** https://ahmadzamani031.github.io/Forushnameh/

## قابلیت‌ها
- ثبت‌نام، ورود، خروج، تأیید ایمیل و بازیابی رمز عبور با Supabase Auth
- مدیریت کالاها و خدمات، قیمت، موجودی و حداقل موجودی
- ثبت اتمیک کالای جدید همراه با موجودی اولیه و دفتر گردش انبار
- مدیریت مشتریان و صدور فاکتور با تاریخ شمسی، تخفیف و مالیات
- جست‌وجو و فیلتر فاکتورها بر اساس شماره، مشتری، تاریخ و وضعیت پرداخت
- چاپ مجدد و خروجی PNG/PDF فاکتور
- دفتر دریافت وجه، پرداخت جزئی، تسویه و برگشت دریافت
- ابطال فاکتور با حفظ سوابق و برگشت موجودی
- گزارش فروش، نمودارها و خروجی PDF/CSV
- تنظیمات کسب‌وکار و واحد پول
- مدیریت مستقل حساب کاربری، نام نمایشی و شماره تماس
- حذف امن حساب از طریق Edge Function و پاک‌سازی داده‌های مرتبط
- پشتیبان‌گیری JSON و بازیابی کنترل‌شده
- تم روشن و تاریک
- PWA قابل نصب با کش پوسته و صفحه آفلاین

## فناوری‌ها
- HTML، CSS و JavaScript بدون فریم‌ورک
- Supabase Auth و PostgreSQL
- GitHub Pages، Service Worker و Web App Manifest
- html2canvas و jsPDF

## داده‌ها و امنیت
داده‌ها در PostgreSQL نگهداری می‌شوند. سیاست‌های RLS و توابع دیتابیس مالکیت و اعتبارسنجی عملیات حساس را کنترل می‌کنند. دریافت‌ها و برگشت‌ها به‌صورت دفتر ثبت append-only نگهداری می‌شوند.

در مرورگر فقط کلید عمومی Publishable استفاده می‌شود. هرگز Service Role Key، رمز دیتابیس یا کلیدهای محرمانه را در مخزن یا کد سمت کاربر قرار ندهید.

## حساب کاربری
نام نمایشی و شماره تماس از بخش «حساب کاربری» قابل مدیریت هستند. شماره تماس فعلاً به‌عنوان اطلاعات پروفایل ذخیره می‌شود و تا زمان راه‌اندازی تأیید پیامکی، تأییدشده محسوب نمی‌شود. حذف حساب پس از تأیید دوبارهٔ هویت، داده‌های کاری و حساب ورود را حذف می‌کند.

## پشتیبان‌گیری
از برنامه فایل JSON پشتیبان دریافت کنید و آن را در مکانی امن نگه دارید. پیش از استفاده عملی، فایل پشتیبان را در یک حساب آزمایشی خالی بازیابی و صحت اطلاعات را بررسی کنید.

## اجرای محلی
مخزن را دریافت و از طریق یک وب‌سرور محلی اجرا کنید. برای Auth، ذخیره‌سازی ابری و امکانات وابسته به کتابخانه‌های بیرونی، اتصال اینترنت لازم است.

## گزارش مشکل
از بخش Issues مخزن برای گزارش خطا استفاده کنید. رمز عبور، کلیدهای محرمانه و اطلاعات شخصی مشتریان را در Issue یا گزارش عمومی قرار ندهید.
