## معرفی

فروش‌نامه یک برنامهٔ تحت وب فارسی و راست‌چین برای مدیریت امور روزمرهٔ فروش است. برنامه با HTML، CSS و JavaScript ساخته شده و از طریق مرورگر اجرا می‌شود؛ برای استفادهٔ معمول نیازی به نصب نرم‌افزار دسکتاپ نیست.

## امکانات نسخهٔ ۸

- **حساب کاربری:** ثبت‌نام، ورود و خروج با ایمیل و رمز عبور از طریق Supabase Auth
- **تأیید ایمیل و بازیابی رمز:** پشتیبانی از تأیید ایمیل و تعیین رمز جدید
- **مدیریت کالاها:** ثبت، ویرایش، غیرفعال‌سازی، قیمت، واحد، کد کالا و حد هشدار موجودی
- **مدیریت مشتریان:** ثبت، ویرایش، غیرفعال‌سازی و جست‌وجو
- **صدور فاکتور:** ثبت اقلام کالا و خدمات، تخفیف و مالیات مبلغی، شماره‌گذاری ترتیبی و خروجی PNG
- **مدیریت انبار:** موجودی اولیه، ورود کالا، خروج بابت فروش و ثبت گردش‌های انبار با کنترل موجودی منفی
- **فاکتورهای قبلی:** مشاهدهٔ فاکتورهای صادرشده و جزئیات اقلام
- **داشبورد و گزارش‌ها:** خلاصهٔ فروش، میانگین فاکتور، روند شش‌ماهه، مشتریان و کالاهای پرفروش
- **تنظیمات کسب‌وکار:** نام، تلفن، نشانی، واحد پول و پیشوند شماره فاکتور
- **پشتیبان‌گیری:** دریافت خروجی JSON از اطلاعات ابری
- **رابط واکنش‌گرا:** قابل استفاده در نمایشگرهای رایانه و تلفن همراه

## معماری ذخیره‌سازی و حریم داده‌ها

احراز هویت از طریق Supabase Auth انجام می‌شود. اطلاعات عملیاتی شامل کالاها، مشتریان، فاکتورها، اقلام فاکتور، گردش انبار و تنظیمات کسب‌وکار در پایگاه دادهٔ PostgreSQL پروژه ذخیره می‌شوند؛ بنابراین داده‌ها به حافظهٔ یک مرورگر خاص محدود نیستند.

جدول‌های اصلی دارای Row Level Security (RLS) هستند و سیاست‌های دسترسی، داده‌ها را به حساب مالک محدود می‌کنند. صدور فاکتور و ثبت گردش انبار از توابع کنترل‌شدهٔ پایگاه داده انجام می‌شود تا شماره‌گذاری و تغییر موجودی به‌صورت یکپارچه صورت گیرد.

**پشتیبان‌گیری:** بخش پشتیبان‌گیری در نسخهٔ فعلی امکان دریافت فایل JSON را فراهم می‌کند. بازیابی فایل پشتیبان در نسخهٔ فعلی فعال نیست؛ فایل خروجی را در مکانی امن نگهداری کنید.

در برنامه فقط از کلید عمومی **Publishable** استفاده می‌شود. کلیدهای `secret` و `service_role` و رمز پایگاه داده نباید در کد مرورگر یا مخزن عمومی قرار بگیرند.

## وضعیت و گام‌های بعدی

نسخهٔ ۸ دارای احراز هویت و ذخیره‌سازی ابری اطلاعات فروش است. تمرکز مراحل بعدی بر بازبینی نهایی، آزمون جریان‌های اصلی، تکمیل مستندات و بهبودهای ضروری خواهد بود؛ نه افزودن قابلیت‌های پیچیده و غیرضروری.
