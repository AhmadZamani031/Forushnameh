# Forushnameh — نسخهٔ ۶

نسخهٔ ششم فروش‌نامه بر پایهٔ نسخهٔ پنجم ساخته شده است.

## امکانات
- داشبورد با خلاصهٔ فروش، تعداد فاکتورها، مشتریان و کالاها
- نمایش آخرین فاکتورها و هشدار کالاهای کم‌موجود
- دسترسی سریع به بخش‌های اصلی
- حفظ امکانات نسخهٔ پنجم: صدور فاکتور و PNG، مدیریت کالا و مشتری، گردش انبار و پشتیبان‌گیری JSON
- رابط کاربری واکنش‌گرا برای رایانه و موبایل
- بازیابی پشتیبان با تلاش برای حفظ داده‌های قبلی در صورت خطای ذخیره‌سازی

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای خروجی PNG اتصال اینترنت جهت بارگذاری html2canvas لازم است.

## ذخیره‌سازی و هشدار
اطلاعات همچنان فقط در localStorage مرورگر ذخیره می‌شوند. پاک کردن داده‌های مرورگر یا تغییر دستگاه می‌تواند دسترسی به اطلاعات را از بین ببرد؛ مرتباً از بخش پشتیبان‌گیری خروجی JSON بگیرید.

## ارتقا از نسخهٔ ۵
کلیدهای ذخیره‌سازی نسخهٔ پنجم حفظ شده‌اند:
- `forushnameh.invoices.v2`
- `forushnameh.products.v1`
- `forushnameh.customers.v1`
- `forushnameh.movements.v1`

بنابراین اگر نسخهٔ ششم را در همان مرورگر و همان دامنهٔ قبلی اجرا کنید، اطلاعات قبلی قابل استفاده خواهند بود. برای انتقال به دامنه/مرورگر دیگر از فایل پشتیبان استفاده کنید.

## فایل‌ها
- `index.html`: ساختار صفحات و داشبورد
- `styles.css`: طراحی و واکنش‌گرایی
- `app.js`: منطق فاکتور، کالا، مشتری، انبار، پشتیبان و داشبورد
- `logo-forushnameh.png`: لوگو


## نسخهٔ ۷ — حساب کاربری و ورود امن

این نسخه به Supabase Auth متصل شده و امکانات زیر را اضافه می‌کند:

- ساخت حساب با نام، ایمیل و رمز عبور
- ورود با ایمیل و رمز عبور
- تأیید ایمیل هنگام ثبت‌نام (در صورت فعال بودن Confirm email در Supabase)
- ارسال پیوند بازیابی رمز عبور و تعیین رمز جدید
- خروج از حساب
- جداسازی داده‌های ذخیره‌شده در مرورگر بر اساس شناسهٔ هر کاربر

### تنظیمات لازم در Supabase

- فعال بودن Email provider
- ثبت Site URL و Redirect URL سایت GitHub Pages در Authentication → URL Configuration
- فعال بودن تأیید ایمیل برای ثبت‌نام

### نکتهٔ مهم دربارهٔ داده‌ها

در نسخهٔ ۷ احراز هویت آنلاین است، اما فاکتورها، کالاها، مشتریان و گردش انبار هنوز در localStorage مرورگر ذخیره می‌شوند و به پایگاه دادهٔ ابری منتقل نشده‌اند. کلیدهای ذخیره‌سازی برای هر حساب جدا هستند. انتقال امن و همگام‌سازی ابری در مرحلهٔ بعد، همراه با طراحی جدول‌ها و سیاست‌های RLS انجام می‌شود.

### تنظیمات اتصال

آدرس پروژه و کلید Publishable در فایل `app.js` قرار دارند. این کلید برای استفاده در مرورگر طراحی شده است. هرگز کلید `secret` یا `service_role` را در کد سمت کاربر قرار ندهید.
