## معرفی

فروش‌نامه یک برنامهٔ تحت وب فارسی و راست‌چین برای مدیریت امور روزمرهٔ فروش است. برنامه با HTML، CSS و JavaScript ساخته شده و از طریق مرورگر اجرا می‌شود؛ برای استفادهٔ معمول نیازی به نصب نرم‌افزار دسکتاپ نیست.

## امکانات نسخهٔ ۷

- **حساب کاربری:** ثبت‌نام و ورود با ایمیل و رمز عبور از طریق Supabase Auth
- **تأیید ایمیل:** پشتیبانی از فرایند تأیید ایمیل هنگام ثبت‌نام
- **بازیابی رمز عبور:** درخواست پیوند بازیابی و تعیین رمز جدید
- **مدیریت فروش:** ثبت و مدیریت فاکتورها و دریافت خروجی تصویری PNG
- **مدیریت اطلاعات:** مدیریت کالاها، مشتریان و گردش موجودی انبار
- **داشبورد:** مشاهدهٔ خلاصهٔ فعالیت‌ها و هشدارهای موجودی
- **پشتیبان‌گیری:** خروجی و بازیابی اطلاعات با فایل JSON
- **رابط واکنش‌گرا:** قابل استفاده در نمایشگرهای رایانه و تلفن همراه
- **تفکیک حساب‌ها در مرورگر:** کلیدهای ذخیره‌سازی محلی بر اساس شناسهٔ کاربر جدا می‌شوند

## معماری ذخیره‌سازی و حریم داده‌ها

در نسخهٔ ۷، احراز هویت از طریق Supabase انجام می‌شود؛ اما اطلاعات عملیاتی شامل فاکتورها، کالاها، مشتریان و گردش انبار هنوز در `localStorage` همان مرورگر ذخیره می‌شوند و به پایگاه دادهٔ ابری منتقل نشده‌اند. بنابراین ورود به حساب در دستگاه یا مرورگر دیگر به معنی همگام‌سازی خودکار اطلاعات فروش نیست.

**پیشنهاد مهم:** از بخش پشتیبان‌گیری برنامه به‌طور منظم فایل JSON تهیه و آن را در مکانی امن نگهداری کنید. پاک شدن داده‌های مرورگر یا استفاده از دستگاه دیگر می‌تواند دسترسی به داده‌های محلی را از بین ببرد.

## پیکربندی Supabase

برای اجرای احراز هویت، پروژهٔ Supabase باید تنظیم شده باشد:

- Email provider فعال باشد.
- نشانی سایت و مسیر بازگشت GitHub Pages در بخش Authentication → URL Configuration ثبت شده باشند.
- تنظیم تأیید ایمیل مطابق سیاست موردنظر پروژه فعال باشد.

در برنامه فقط از کلید عمومی **Publishable** استفاده می‌شود. کلیدهای `secret` و `service_role` و رمز پایگاه داده نباید در کد مرورگر یا مخزن عمومی قرار بگیرند.
