# فروش‌نامه

نرم‌افزار فارسی و راست‌چین مدیریت فروش، فاکتور، کالا، مشتری و موجودی انبار.

**نسخهٔ آنلاین:** https://ahmadzamani031.github.io/Forushnameh/

## امکانات

- ثبت‌نام، ورود و بازیابی رمز عبور
- مدیریت کالاها، قیمت‌ها و موجودی
- مدیریت مشتریان
- صدور فاکتور با تاریخ شمسی
- خروجی فاکتور به‌صورت تصویر PNG و فایل PDF
- ثبت گردش انبار و کنترل موجودی منفی
- مشاهدهٔ فاکتورهای صادرشده
- گزارش فروش و داشبورد
- تنظیمات کسب‌وکار و واحد پول
- دریافت نسخهٔ پشتیبان JSON از اطلاعات ابری

## فناوری‌ها

- HTML، CSS و JavaScript
- Supabase Auth و PostgreSQL
- html2canvas و jsPDF برای خروجی فاکتور
- GitHub Pages برای میزبانی

## ذخیره‌سازی و امنیت

احراز هویت از طریق Supabase Auth انجام می‌شود. اطلاعات کالاها، مشتریان، فاکتورها، اقلام فاکتور، گردش انبار و تنظیمات کسب‌وکار در PostgreSQL ذخیره می‌شوند.

سیاست‌های Row Level Security دسترسی به داده‌ها را به حساب مالک محدود می‌کنند. صدور فاکتور و ثبت گردش انبار از توابع کنترل‌شدهٔ پایگاه داده انجام می‌شود.

در کد سمت کاربر فقط کلید عمومی Publishable استفاده می‌شود. کلیدهای Secret و Service Role و رمز پایگاه داده نباید در مخزن یا مرورگر قرار بگیرند.

## پشتیبان‌گیری

از بخش پشتیبان‌گیری می‌توان فایل JSON شامل اطلاعات حساب، تنظیمات، کالاها، مشتریان، فاکتورها، اقلام فاکتور و گردش انبار دریافت کرد. فایل پشتیبان را در مکانی امن نگهداری کنید. بازیابی فایل از داخل برنامه در دسترس نیست.

## اجرای محلی

۱. مخزن را دریافت کنید.
۲. فایل `index.html` را با مرورگر باز کنید.
۳. برای ورود، ذخیره‌سازی ابری و دریافت خروجی فاکتور به اینترنت نیاز دارید.

## گزارش مشکل

برای گزارش خطا یا پیشنهاد، از بخش Issues مخزن استفاده کنید. در گزارش‌ها رمز عبور، کلیدهای محرمانه و اطلاعات شخصی مشتریان را قرار ندهید.
