# فروش‌نامه

فروش‌نامه یک نرم‌افزار فارسی و راست‌چین برای مدیریت فروش و امور روزمره کسب‌وکارهای کوچک است. این برنامه با رابط کاربری ساده، امکان مدیریت کالاها، مشتریان، فاکتورها، دریافت‌ها و گزارش‌های فروش را فراهم می‌کند.

## امکانات

- ثبت‌نام، ورود، خروج، تأیید ایمیل و بازیابی رمز عبور
- مدیریت کالاها و خدمات، قیمت، موجودی و حداقل موجودی
- ثبت کالای جدید همراه با موجودی اولیه و ثبت گردش انبار
- مدیریت مشتریان و صدور فاکتور با تاریخ شمسی، تخفیف و مالیات
- جست‌وجو و فیلتر فاکتورها بر اساس شماره، مشتری، تاریخ و وضعیت پرداخت
- چاپ فاکتور و دریافت خروجی PNG و PDF
- ثبت دریافت نقدی و سایر روش‌های پرداخت، پرداخت جزئی، تسویه و برگشت دریافت
- ابطال فاکتور با حفظ سوابق و برگشت موجودی
- گزارش فروش، نمودارها و خروجی PDF و CSV
- تنظیمات کسب‌وکار و واحد پول
- مدیریت حساب کاربری، نام نمایشی و شماره تماس
- حذف حساب کاربری و داده‌های مرتبط از مسیر امن سمت سرور
- پشتیبان‌گیری و بازیابی کنترل‌شده اطلاعات با فایل JSON
- تم روشن و تاریک
- قابلیت نصب به‌صورت وب‌اپلیکیشن (PWA) و نمایش صفحه راهنمای آفلاین

## فناوری‌ها

- HTML، CSS و JavaScript بدون فریم‌ورک
- Supabase Auth و PostgreSQL برای احراز هویت و ذخیره‌سازی داده‌ها
- Service Worker و Web App Manifest برای قابلیت نصب و مدیریت پوسته برنامه
- کتابخانه‌های html2canvas و jsPDF برای خروجی و چاپ

## ساختار مخزن

| مسیر | کاربرد |
|---|---|
| `index.html` | صفحه اصلی و محیط مدیریت |
| `about.html`, `contact.html`, `faq.html` | صفحات معرفی، تماس و راهنما |
| `privacy.html`, `terms.html` | صفحات حریم خصوصی و شرایط استفاده |
| `styles.css` | طراحی واکنش‌گرا، راست‌چین و تم‌ها |
| `app.js` | منطق برنامه و ارتباط با Supabase |
| `site.js` | منوی صفحات عمومی و هماهنگی تم و لوگو |
| `service-worker.js` | مدیریت پوسته کش‌شده و رفتار آفلاین |
| `manifest.webmanifest` | مشخصات نصب وب‌اپلیکیشن |
| `supabase/migrations/` | تغییرات ساختار پایگاه داده |
| `supabase/functions/delete-account/` | تابع سمت سرور برای حذف حساب کاربری |
| `logo-forushnameh.svg`, `logo-forushnameh-dark.svg` | لوگوی اصلی در تم روشن و تاریک |

## داده‌ها و امنیت

اطلاعات کسب‌وکار در پایگاه داده PostgreSQL نگهداری می‌شوند. سیاست‌های امنیت در سطح ردیف (RLS) و توابع پایگاه داده، دسترسی کاربران به اطلاعات و عملیات حساس را کنترل می‌کنند.

در کد سمت مرورگر فقط از کلید عمومی Supabase استفاده می‌شود. کلیدهای محرمانه و دسترسی مدیریتی باید فقط در تنظیمات امن سمت سرور نگهداری شوند.

## حساب کاربری

نام نمایشی و شماره تماس از بخش «حساب کاربری» مدیریت می‌شوند. شماره تماس تا زمانی که فرایند تأیید پیامکی فعال نشده باشد، تأییدشده محسوب نمی‌شود. حذف حساب پس از تأیید هویت انجام می‌شود و اطلاعات مرتبط با حساب نیز طبق فرایند حذف برنامه پاک‌سازی می‌شوند.

## پشتیبان‌گیری و بازیابی

از بخش پشتیبان‌گیری، فایل JSON اطلاعات دریافت می‌شود و می‌توان آن را در شرایط پشتیبانی‌شده بازیابی کرد. فایل‌های پشتیبان را در مکانی امن نگهداری کنید و پیش از بازیابی اطلاعات مهم، محتوای فایل را بررسی کنید.

## اجرای محلی

مخزن را دریافت کنید و فایل‌ها را از طریق یک وب‌سرور محلی اجرا کنید. برای ورود کاربران، ذخیره‌سازی ابری و امکانات وابسته به سرویس‌های بیرونی، تنظیمات معتبر Supabase و اتصال اینترنت لازم هستند.

## گزارش خطا

برای گزارش مشکل یا پیشنهاد بهبود، از بخش Issues همین مخزن استفاده کنید. لطفاً رمز عبور، کلیدهای محرمانه و اطلاعات شخصی مشتریان را در گزارش‌های عمومی قرار ندهید.
