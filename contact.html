پیشنهاد یا پرسشی دارید؟

برای گزارش مشکل فنی، پیشنهاد قابلیت جدید یا پیگیری موضوعات مربوط به توسعه فروش‌نامه، از صفحه رسمی پروژه در GitHub استفاده کنید.

ثبت درخواست و گزارش مشکللطفاً در درخواست خود، شرح موضوع، مراحل بازتولید مشکل و تصویر خطا (در صورت وجود) را بنویسید. هرگز رمز عبور یا اطلاعات حساس حساب خود را ارسال نکنید.رفتن به صفحه ارتباط در GitHub

در حال حاضر، کانال عمومی GitHub راه ارتباطی معرفی‌شده برای پروژه است. نشانی ایمیل یا شماره تماس مستقلی برای پشتیبانی در این صفحه اعلام نشده است.
